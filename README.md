### 🚀 Featured Architecture: Bazar K-12 (Closed Source / Production)
*Due to client confidentiality, the core backend repository for this project is private, but here is the architectural overview of what I built from 0 to 1.*

**Full-Stack POS & Inventory Management System**
Architected a highly concurrent Point of Sale system managing a live catalog of **2,800+ products** to digitize a retail client's operations, reducing their operational costs by 82%.
* **Backend:** Built a robust REST API using **Python (Flask)**. Instead of relying on ORMs, I wrote and optimized **parameterized raw SQL** queries for a Turso (SQLite at the edge) database to prevent injection vulnerabilities and ensure strict data integrity during concurrent stock transactions.
* **Frontend:** Responsive SPA built with **JavaScript/Angular** and Tailwind CSS.
* **Infra & Workflow:** Automated CI/CD pipelines via **GitHub Actions** and containerized the environment using **Docker**. Leveraged LLMs to prototype complex SQL JOINs for real-time financial reporting.
